horicx.

A real home for your music.

The application code is prepared for Supabase PostgreSQL, Auth, private Storage and Edge Functions. A project must be provisioned before cloud accounts or music uploads can work.

1. Create your project

Sign in at Supabase, choose your organisation, create a project named Horicx Music and select an appropriate region and plan. Keep the database password and all server keys private.

2. Apply the backend from your checkout

npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase db push
npx supabase secrets set ALLOWED_ORIGINS="https://YOUR_FRONTEND_ORIGIN"
npx supabase functions deploy music-api --no-verify-jwt

Enable email authentication and anonymous listener sessions in Supabase Auth. Configure your frontend origin as the Site URL and an allowed redirect URL. Configure a sender for signup and password recovery email.

3. Set up the requested administrator

npm run setup:admin

The terminal helper creates the intended administrator through Supabase Auth and grants its protected database role. It asks for privileged credentials and your chosen password using hidden terminal input; none are placed in the website bundle. Existing account passwords are never silently overwritten.

4. Connect and verify the frontend

Set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY in your frontend build environment. Use only the public publishable/anon key. Then run:

npm run build
npm run check:production

Rebuild and deploy after configuration. Sign in to the admin studio to upload your first MP3, artwork and advert. New projects start with an empty catalogue. Read the repository README for the full setup and verification steps.
